# Улучшение UI/UX сообщений Telegram-бота (карточка предмета и списки)

## Контекст

На скриншоте — карточка предмета (`format_course_details`): секции «Регистр · 5», «Оценки · 12», «Задания · 15» различаются только цветом ссылок, оценки 52.00 и 100.00 выглядят одинаково, просроченные задания «шумят» в общем списке, даты длинные («21.11.2026 00:00»), названия заданий с мусорной капитализацией («endterm», «quiz 1 marks»). Выбранный стиль: **минимализм без декоративных эмодзи** + **цветные точки у баллов** (🟢 ≥90, 🟡 50–89, 🔴 <50 — 50 проходной AITU) + **просроченные сворачиваются** в раскрывающийся блок Telegram.

## Изменения

### 1. `app/notifications/formatter.py` — основные правки

Новые приватные хелперы:
- `_score_dot(item) -> str` — «🟢/🟡/🔴/""»: процент из `grade_raw`/`grade_max`, при отсутствии — парсинг `percentage`; без данных — пусто.
- `_compact_dt(dt, tz, now) -> str` — «сб 21.11, 00:00» (год опускается, если совпадает с текущим; иначе «сб 21.11.2026, 00:00»). Дни недели: пн–вс.
- `_display_title(name) -> str` — капитализация первой буквы («endterm» → «Endterm»), только для отображения.
- `_remaining_short(due, now) -> str` — «через 3 д.» / «через 5 ч.» / «через 40 мин.» (без «осталось», часы/минуты опускаются при днях ≥1).
- В `_format_grade_score` — срезка хвостовых «.00» («77.00» → «77», «82.76» остаётся).

Переработка функций:
- `format_course_details` — макет выше: жирные заголовки секций капсом со счётчиками; точки у каждого балла (Регистр и Оценки); задания: предстоящие с компактной датой и «через …», сданные с «сдано» курсивом; прошедшие (в т.ч. сданные) — в `<blockquote expandable>` со статусом «сдано»/«не сдано». Сортировка сохраняется (предстоящие → прошедшие).
- `format_deadlines_list` — 2 строки на элемент вместо 3: заголовок-ссылка + «Курс · сб 21.11, 00:00 · через 3 д.» («сдано»/«срок истёк» курсивом).
- `format_grades_list` — точка у балла, дата оценки в компактном виде на той же строке: «• Attendance — 🟡 85.19 / 100 · 12.11».

Не трогаем: `format_remaining_time`, `format_local_dt`, уведомления (`format_grade_notification` и др.) — их используют `personal.py`/`service.py`, формат стабильный.
