# Интеграция регламента оценивания AITU: допуск, Total, буква, GPA

## Контекст

Пользователь предоставил официальный регламент: РК1/РК2 ≥ 25 и Register Term ≥ 50 для допуска к экзамену (иначе летник), Total = РК1×0.3 + РК2×0.3 + Final×0.4, шкала Total → буква/GPA (A 4.0 95–100 … FX 30–49, F 0–29). В [scholarship.py](C:\Users\Пользователь\.gemini\antigravity\scratch\moodle_tg_notifier\app\scholarship.py) уже есть формула и классификация финала, но нет проверки допуска и шкалы GPA. Решение пользователя: добавить блок «ИТОГ» в карточку предмета; при недопуске — жёсткий блок (расчёт стипендии не показывается как достижимый).

## Изменения

### 1. `app/scholarship.py` — функции регламента

- `GRADE_SCALE` — таблица шкалы: (letter, gpa, min_total, max_total) — 12 строк от A(95–100, 4.0) до F(0–29, 0).
- `total_to_letter_gpa(total: float) -> tuple[str, float]` — сопоставление Total со шкалой (границы включительные; < 30 → F, 30–49 → FX).
- `AdmissionStatus` (dataclass: `admitted: bool`, `register_term: float | None`, `problems: list[str]`).
- `check_admission(midterm, endterm) -> AdmissionStatus` — РК1 ≥ 25, РК2 ≥ 25, Term = (РК1+РК2)/2 ≥ 50; проблемы в виде «РК Midterm 22 < 25», «Register Term 37.5 < 50».
- В `analyze_course_scholarship` (курс в процессе): если `check_admission` не пущен → `status_text = "⚠ Не допущен к экзамену — летник"` вместо расчёта стипендии (жёсткий блок, автоматически виден в «Стипендии по предметам»).

### 2. `app/notifications/formatter.py` — блок «ИТОГ» в карточке

В `format_course_details` после секции «ОЦЕНКИ», перед «ЗАДАНИЯ», при наличии РК1/РК2 (через существующую `extract_course_registers`, импорт из `app.scholarship` — циклической зависимости нет):

**Допущен, финал не выставлен:**
```
ИТОГ · ДОПУСК ЕСТЬ
• РК1 77 · РК2 80 · Term 78.5
• Набрано: 47.1 / 60
• На финале: от 50 — сдача (итог 67, C) · от 57 — стипендия (итог 70, C+)
```
(минимальный финал для сдачи = `effective_final_for_scholarship(calculate_required_final(m, e, 50))`, для стипендии — цель 70; прогноз Total = текущие баллы + 0.4×мин_финал; буква/GPA через `total_to_letter_gpa`)

**Финал выставлен:**
```
ИТОГ
• РК1 77 · РК2 80 · Финал 82 — сдан
• Total 79.4 → B- (2.67)
```
(Total — из Register Total Moodle, иначе расчёт по формуле)

**Недопуск (жёсткий блок):**
```
ИТОГ · ⚠ НЕ ДОПУЩЕН
• РК1 22 · РК2 80 · Term 51
• РК Midterm 22 < 25 — летник
```

Если РК1/РК2 не найдены в оценках — блок не выводится (без шума).

- `tests/unit/test_formatter.py` — карточка: блок ИТОГ при допуске/недопуске/выставленном финале, отсутствие блока без РК.
